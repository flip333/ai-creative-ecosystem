# Contexto de UX/UI y Arquitectura de Navegación: Genflow (Portal de Cliente)

## 1. Ruta de Navegación Sugerida (User Flow - UX)

El flujo está diseñado para reducir la carga cognitiva del cliente, llevándolo de lo general (impacto de negocio) a lo particular (detalles técnicos de cada automatización).

1. **Autenticación (Login):** Acceso seguro para el cliente.
2. **Onboarding / Vista General (Home/Dashboard):** Al entrar, el usuario ve un resumen de alto nivel: total de automatizaciones activas, ahorro de tiempo/dinero estimado y alertas de sistemas detenidos.
3. **Hub de Automatizaciones (Core del requerimiento):** La tabla principal donde el cliente audita todo lo que Genflow ha construido para él.
4. **Detalle de Automatización (Deep Dive):** Al hacer clic en un flujo específico, el usuario entra a una vista detallada para ver métricas específicas, registros de ejecución (logs) y acceder a los manuales de uso.
5. **Facturación y Ecosistema (Billing & Stack):** Un área para revisar los costos de las herramientas subyacentes (N8N, GoHighLevel, OpenAI, etc.) y los servicios de Genflow.

---

## 2. Diagrama de Navegación (Sitemap)

- **[ 🏠 Inicio / Resumen ]** (Dashboard Ejecutivo)
  - Métricas Globales (ROI, leads generados, horas ahorradas)
  - Alertas del Sistema
- **[ ⚙️ Mis Automatizaciones ]** (El Dashboard Principal solicitado)
  - Vista de Tabla / Tarjetas
  - Filtros (Por estado, por área de negocio)
  - **[ 📄 Detalle de Flujo ]** (Vista individual)
    - Gráfico de la secuencia (Visualización simplificada)
    - Historial de ejecuciones
- **[ 📚 Centro de Documentación ]**
  - Manuales de identidad o de usuario de los sistemas
  - Prompts maestros utilizados
- **[ 💳 Facturación y Costos ]**
  - Desglose de costos de infraestructura y licencias
- **[ 🎧 Soporte / Tickets ]**
  - Solicitud de ajustes o reporte de fallos

## 3. Estructura del "Dashboard de Automatizaciones" (UI)

Esta será la pantalla principal donde interactuará el cliente. Se sugiere un diseño tipo tabla de datos (Data Grid) o listado de tarjetas enriquecidas.

### Columnas y Datos de la Interfaz:

1. **Función (Nombre / Descripción):**
   * *UI Suggestion:* Texto en negrita con el nombre del flujo (ej. "Secuencia Onboarding Clientes") y un subtítulo gris con la plataforma base (ej. "N8N + GoHighLevel").
2. **Status (Estado):**
   * *UI Suggestion:* Etiquetas (Pills) semánticas. 
     * 🟢 Activo (Verde)
     * 🟡 En Pausa / Mantenimiento (Amarillo)
     * 🔴 Error / Detenido (Rojo)
3. **Última Actualización:**
   * *UI Suggestion:* Texto simple (ej. "Hace 2 horas", "14/May/2026").
4. **Documentación:**
   * *UI Suggestion:* Un botón fantasma (Ghost Button) o ícono de enlace externo (🔗) que lleve directamente al manual de usuario o diagrama de arquitectura de esa automatización específica.
5. **Costo (Mensual / Por ejecución):**
   * *UI Suggestion:* Valor monetario destacable, idealmente separando el costo de la herramienta (ej. tokens de IA) del costo de gestión si aplica.
6. **Resultados (Impacto):**
   * *UI Suggestion:* Un minigráfico (Sparkline) o una métrica clave en verde (ej. "+45 Leads procesados", "12 horas ahorradas").

### Elementos de Interacción (Actionables):
* **Barra de Búsqueda:** Para encontrar flujos rápidamente.
* **Botón de Filtro:** Para ocultar flujos inactivos o filtrar por área (Ventas, Marketing, Operaciones).
* **Botón de Acción (Call to Action):** "Solicitar nueva automatización".
